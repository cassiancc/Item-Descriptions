### Added
- Support for 1.21.9 snapshots, alongside descriptions for currently released 1.21.9 content.
- Enchantment Descriptions are now visible when using [Quark](https://modrinth.com/mod/quark)'s Matrix Enchanting feature.
- Mod name tooltip now better handles mod IDs with spaces.
- Mod name tooltip now respects `getCreatorModId` (NeoForge/MinecraftForge) and `getCreatorNamespace` (Fabric 1.21.8+).

### Fixed
- Revised descriptions and fixed some minor typos in existing descriptions.
