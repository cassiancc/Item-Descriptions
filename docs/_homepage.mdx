Welcome to the wiki for Item Descriptions! This mod adds unique descriptions to all vanilla blocks, items, entities, and tags, alongside support for modded items through tag descriptions and resource packs.

While the focus of the main mod is content in vanilla Minecraft and the 1.21+ common tags, it can be easily expanded to add more descriptions to modded blocks, or get started with custom descriptions, this is where to be!


## Resource Packs
- [Mod Descriptions](https://modrinth.com/resourcepack/mod-descriptions) adds support for various mods.
- [No Descriptions](https://github.com/cassiancc/No-Descriptions/releases) removes all built-in descriptions.

## Mod Developers
If you want your mod to support Item Descriptions, I would encourage including Item Descriptions translations in your mod itself.

- [Adding Descriptions to Modded Blocks/Items](/en/mod/item-descriptions/docs/mods/Modded-Blocks) covers what to do to add support for Item Descriptions to your mod's blocks and items.
- [Adding Descriptions to Modded Tags](/en/mod/item-descriptions/docs/mods/Modded-Tags) covers what to do to add support for Item Descriptions to your mod's tags.
- [Adding Descriptions to Modded Entities](/en/mod/item-descriptions/docs/mods/Modded-Entities) covers what to do to add support for Item Descriptions to your mod's entities.

## Modpack Developers

If you have mods that you want to support Item Descriptions, you can either make your own custom resource pack with Item Descriptions translations, or contribute them to [Mod Descriptions](https://github.com/cassiancc/Mod-Descriptions) as a Pull Request, which is focused on providing descriptions for as many mods as possible.

Built-in Item Descriptions can also be overridden by resource packs, if you want to add custom content for your modpack. If you want to start from a blank slate, try out the [No Descriptions](https://github.com/cassiancc/No-Descriptions/releases) resource pack, which removes all built-in descriptions.

- [Adding Descriptions to Modded Blocks/Items](/en/mod/item-descriptions/docs/mods/Modded-Blocks) covers what to do to add support for Item Descriptions to blocks and items from mods that you use.
- [Adding Descriptions to Modded Tags](/en/mod/item-descriptions/docs/mods/Modded-Tags) covers what to do to add support for Item Descriptions to any tags that your mods support.
- [Adding Descriptions to Modded Entities](/en/mod/item-descriptions/docs/mods/Modded-Entities) covers what to do to add support for Item Descriptions to your entities in the mods that you use.

## For Datapackers

If you want your custom items to have custom Item Descriptions, you can make your own [custom resource pack](https://minecraft.wiki/w/Tutorial:Creating_a_resource_pack) and follow the guides below.

Built-in Item Descriptions can also be overridden by resource packs.  If you want to start from a blank slate, try out the [No Descriptions](https://github.com/cassiancc/No-Descriptions/releases) resource pack, which removes all built-in descriptions.

- [Adding Descriptions to Items with Custom Model Data](/en/mod/item-descriptions/docs/Custom-Model-Data) covers what to do to add Item Descriptions to items with [Custom Model Data](https://www.planetminecraft.com/forums/communities/texturing/new-1-14-custom-item-models-tuto-578834/).
- [Adding Descriptions to Players](/en/mod/item-descriptions/docs/data/Player-Descriptions) covers what to do to add Item Descriptions to specific Players.
- [Adding Descriptions to Player Heads](/en/mod/item-descriptions/docs/data/Player-Heads) covers what to do to add Item Descriptions to specific Player Heads.
- [Adding Descriptions to Paintings](/en/mod/item-descriptions/docs/data/Paintings) covers what to do to add Item Descriptions to specific Player Heads.

## Translators
If you're interested in translating Item Descriptions to your language, please send in a Pull Request with these descriptions to the main mod. If you are not comfortable with GitHub, I also accept submissions via my Discord server (linked on this mod's [Modrinth page](https://modrinth.com/mod/item-descriptions))
