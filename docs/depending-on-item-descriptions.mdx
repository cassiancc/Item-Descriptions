# Depending on Item Descriptions

While Item Descriptions is entirely handled via resource packs, mod developers may want to add it to their developer environment in order to easily test against the mod. For that reason, it is available on my maven.

## gradle.properties
```groovy
item_descriptions_version = 2.5.1
```

## Adding the maven (`build.gradle`)
```groovy
repositories {
    maven {
        name = "cassian's maven"
        url = "https://maven.cassian.cc"
    }
}
```

## Fabric Loom/Architectury Loom
```groovy
modImplementation "cc.cassian.item_descriptions:item-descriptions-fabric:${item_descriptions_version}+${minecraft_version}"
```

## NeoForge/ModDevGradle
```groovy
implementation "cc.cassian.item-descriptions:item-descriptions-neoforge:${item_descriptions_version}+${minecraft_version}"
```

## Forge
```groovy
implementation(fg.deobf("cc.cassian.item-descriptions:item-descriptions-forge:${item_descriptions_version}+${minecraft_version}"))
```
